Taruh file gambar di folder ini (opsional) supaya game pakai asetmu sendiri:

  player.png   -> karakter yang dikendalikan (disarankan persegi, mis. 128x128px, PNG transparan)
  enemy.png    -> musuh
  dot.png      -> titik kecil yang dikumpulkan
  wall.png     -> tekstur dinding (akan di-tile berulang per petak)
  bg.png       -> background area jalan labirin (otomatis diskalakan ke ukuran labirin)

Format yang didukung: .png (disarankan, mendukung transparansi) atau .jpg/.jpeg.
Kalau nama file di atas TIDAK ada di folder ini, game otomatis pakai bentuk
warna sederhana sebagai gantinya -- jadi kamu bisa coba main dulu sebelum
asetnya jadi, lalu tinggal taruh file png-nya di sini kapan saja tanpa ubah kode.

PENTING: nama file harus PERSIS seperti di atas (huruf kecil semua).
